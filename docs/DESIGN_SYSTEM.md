# Design system

Refined healthcare direction: warm off-white, deep teal, sage and sand, locally hosted Inter/Manrope and a restrained Georgia italic hero accent. Source tokens and component layouts are in src/app/globals.css.

The editorial homepage uses a labelled AI-generated illustration of fictional people. It is not a testimonial or a claim about actual providers. The original generated image was copied into public/images/care-hero.png; no clinical data was used.

The workspace uses a persistent desktop sidebar, mobile navigation drawer, compact truthful metrics, dedicated workflows, structured forms, status badges and clear empty/error/loading states. Small supporting text was darkened after contrast review. Buttons use the customised CVA/Slot primitive; icon and typography choices are consistent across roles.

Responsive review widths: 390, 768, 1440. Homepage overflow checks and axe WCAG A/AA pass. Dashboard visual/accessibility review remains pending real authenticated execution. Respect reduced motion and visible keyboard focus. Charts display recorded mobility minutes only and make no clinical outcome claim.
